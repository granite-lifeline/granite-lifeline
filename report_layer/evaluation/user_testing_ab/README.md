# Report Layer user-testing stimuli

Five named Seat Leon CSV trips are processed together by Data Layer, then
once by Model Layer. The saved Model output is used to generate the report.

**Historical design note:** the original goal was a blind RAG/no-RAG
comparison (conditions "A" and "B", generated by `run_user_testing_ab.py`).
Early outputs did not show a clear or consistent difference suitable for the
Dashboard user study. The final study therefore used only the reviewed RAG
report and assessed the complete Dashboard, including report readability.
The retrieval and prompt issues observed here informed later Report Layer
changes and the controlled V5 evaluation.

`run_user_testing_ab.py`, condition A and `administrator-condition-key.json`
are kept for reproducibility of that investigation, not as the current
study design. The "A"/"B" labels never appeared in the Dashboard UI itself
— they only exist in this directory's file names and the admin-only key.
