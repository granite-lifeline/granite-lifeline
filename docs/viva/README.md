# Viva Presentation — Collaboration Guide

## Overview
The final viva presentation is 10 minutes
followed by 10-15 minutes Q&A on Microsoft
Teams in September. All 6 members must
present.

## Structure
Each group drafts their own layer's key
points in their markdown file. Charlotte
assembles the final HTML slide deck.

## Files
- outline.md — overall slide structure
  and timing
- data_layer.md — Data Layer key points
  (Lei Pei, Qiuting Fu)
- model_layer.md — Model Layer key points
  (Ray Wang, Lucca Zhou)
- report_layer.md — Report Layer and
  Dashboard key points
  (Charlotte Yu, Jintong He)

## How to contribute
1. Open your group's markdown file
2. Fill in the sections marked TODO
3. Follow the format already in the file
4. Raise any questions in Discord
